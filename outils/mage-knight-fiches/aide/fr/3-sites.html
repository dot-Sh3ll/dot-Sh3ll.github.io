Les sites

Ennemis errants
Provoqué en passant d'une case adjacente à une autre, ou défié comme Action.
Pas de déplacement sur la case. 
Orques maraudeurs
  • Ennemi vert révélé
  • Récompense : +1 Réputation
Draconien
  • Ennemi rouge révélé
  • Récompense : +2 Réputation
Sites fortifiés
Assaut : Faire un déplacement selon le terrain, −1 Réputation, défenseur Fortifié.
Forteresse
  • Ennemi gris caché
    Révélé de jour si joueur adjacent
  • Si conquise : 1 Bouclier
  • Recruter (icône      )
  • Fin de tour dedans/à côté : limite de main +1
  • PvP : un autre joueur peut l'attaquer
Tour de Mage
  • Ennemi violet caché
    Révélé de jour si joueur adjacent
  • Si conquise : 1 Bouclier + 1 Sort
  • Puis pour tous : recruter (icône    )
  • Acheter : 7 Influence + 1 mana → 1 Sort
Lieux sans combat
Village
  • Recruter (icône      )
  • Soigner : 3 Influence → 1 Soin
  • Piller (tour d'un autre joueur) :
    −1 Réputation, +2 cartes
Monastère
  • Recruter (icône      )
  • Soigner : 2 Influence → 1 Soin
  • Entraînement :
    6 Influence → 1 Action Avancée
  • Brûler le monastère :
    −3 Réputation, ennemi violet
    Vos unités ne participent pas
    Récompense : 1 Bouclier + 1 Artefact
Mine de Cristal
  • Finir votre tour dessus : 1 Cristal de sa couleur
Clairière magique
  • Début de tour : mana or (Jour) / noir (Nuit)
  • Fin de tour : détruisez 1 Blessure

Gains reçus en fin de tour · Cristal au dé : or = au choix, noir = 1 Gloire · Artefact : piochez 2, gardez 1 · ● = danger.
